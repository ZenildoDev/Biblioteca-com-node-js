-> Contador de Palavras (CLI)
Este projeto é uma aplicação em Node.js desenvolvida como parte dos estudos na plataforma de ensino Alura. A aplicação lê um arquivo .txt, conta as palavras repetidas por parágrafo e gera 
um arquivo com o resultado contendo apenas as palavras que aparecem mais de uma vez.O programa funciona via linha de comando (CLI). Ele recebe o caminho de um arquivo de texto, processa seu conteúdo, 
identifica as ocorrências das palavras em cada parágrafo e cria um arquivo resultado.txt com as palavras duplicadas encontradas.

-> Funcionalidades

Leitura de arquivo .txt, Contagem de palavras por parágrafo, Filtro de palavras que aparecem mais de uma vez, Geração automática de um arquivo resultado.txt, Execução via terminal utilizando comandos personalizados

-> Tecnologias utilizadas

Node.js, Módulo fs (File System), Módulo path, Biblioteca commander para criação da interface de linha de comando
